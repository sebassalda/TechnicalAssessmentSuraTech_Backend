## Description (as written by the author)

> Adds Chile (Austral Pagos) payment notifications to the prototype, so we can switch off the nightly import for Chile before the month-end peak.
>
> - New endpoint `POST /webhooks/austral` that validates the Austral signature.
> - Processing is async so we always answer Austral fast (their timeout is 10 s and Salesforce can be slow).
> - Idempotent: we store the processed `eventId` in Azure SQL and skip duplicates.
> - If the payment already exists in Salesforce we update its status; otherwise we create it.
> - Unit tests generated with Copilot, all green ✅
> - The webhook secret is in `application.yml` for now; I'll move it to Key Vault in a follow-up PR.
>
> Tested locally with the samples in `reference/providers/austral-cl/samples/`.
